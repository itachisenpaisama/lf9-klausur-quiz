2. IPv6 RFC 5952 Verkürzungsregeln

  • Führende Nullen: In jedem Block streichen (z.B. 0db8 → db8, 0000 → 0).
  • Doppel-Doppelpunkt ::: Nur 1x in der gesamten Adresse für 2 oder mehr aufeinanderfolgende 0-Blöcke.
  • Längste Folge: :: wird immer auf die längste Nullfolge angewendet.
  • Gleichstand-Regel (Links vor Rechts): Sind zwei Null-Folgen exakt gleich lang, MUSS die ERSTE (linke) Folge verkürzt werden! (z.B. 2001::1:0:0:2).
  • Scopes: fe80::/10 = Link-Local | fc00::/7 = ULA (Privat) | 2000::/3 = Global Unicast | ff00::/8 = Multicast | ::1/128 = Loopback.

4. VPN & Firewall (DMZ-Prinzip)

  • Site-to-Site VPN: Dauerhafte Verbindung zweier Standorte (Filialkopplung über Router/Firewall-Gateway). Transparent für Endgeräte.
  • End-to-Site VPN (Roadwarrior): Mobiler Client verbindet sich von unterwegs/Home-Office über VPN-Software ins Firmen-Gateway.
  • DMZ (Demilitarisierte Zone): Isolierte Pufferzone für öffentlich erreichbare Server (Web, Mail). Verhindert, dass ein gekaperter Server Zugriff auf das interne Firmennetz erhält (Regel: Internet → DMZ erlaubt, aber DMZ → LAN streng verboten).
  • Stateful Packet Inspection (SPI): Firewall merkt sich den Verbindungsstatus in einer Zustandstabelle (State Table) und erlaubt nur eingehende Pakete, die zu einer aktiv angeforderten ausgehenden Verbindung gehören.
